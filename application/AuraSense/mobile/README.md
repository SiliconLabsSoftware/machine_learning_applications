# Mobile App

This folder contains the Android side of AuraSense.

## What Is Here

- `aurasense-android-app/` - Android Studio project for the caregiver app

## What The App Does

- Connects to the AuraSense EFR32xG26 device over BLE
- Displays live cry classification state and confidence
- Shows room-temperature data when available
- Lets the caregiver manage alert settings
- Raises alerts and escalation notifications on the phone
