# Datasets

This folder documents the training data source for AuraSense.

## Included Here

- Dataset notes and placeholders used for the project structure
- `datasets.txt` with the dataset reference link

## Dataset Reference

The current dataset pointer is stored in:

- `datasets.txt`

At the time this repo snapshot was prepared, that file points to a Google Drive dataset location used during project work.

## Important Note

Public repositories often should not store full raw audio datasets directly when the data is large, private, or still being curated. This folder keeps the project organized while pointing collaborators to the dataset source.
